# groschenfall-studio

Produktions-Pipeline für **Groschenfall** (YouTube + TikTok): „Der Groschen fällt: Geldfallen im Alltag – in 40 Sekunden durchschaut.“ Rangfolge der Regeln: siehe `docs/KANAL_REGELN.md`.

- `NIGHT_RUN.md` – Ablauf der nächtlichen Produktion (Pflichtlektüre für jeden Lauf)
- `docs/KANAL_REGELN.md` – feste Regeln des Kanals
- `docs/brand/` – Marke v2 (seit 05.11.2026): POSITIONIERUNG, STIMME, LOOK (Maskottchen „Der Groschen“), SERIEN
- `docs/STUDIO_HANDBUCH.md` – Viral-Regeln G1–G10 für alle Studio-Kanäle
- `docs/AUSWERTUNG_AKTUELL.md` – laufender Test + Messziele
- `docs/PLAYBOOK.md` – Handwerk: Themen-Scoring, Hooks, Skript, Titel, Thumbnail, Kritiker-Rubrik
- `remotion/` – Remotion-Projekt (Kit: `src/kit`, `src/v5/kit5.tsx`; Vorlagen: `src/ch/Short8.tsx`, `src/v5/V5Ch*.tsx`, `src/ch/Thumb5.tsx`)
- `tools/gf.py` – Stimme aufbereiten, Wort-Timing, Timing-JSONs, Musik-Mix, Untertitel, Kompression
- `assets/music/` – Musikbetten (ElevenLabs Music)
- `state/` – erledigte Themen + Log der Nachtläufe
- `legacy/` – alte Einzelskripte (nur Referenz)
